# Materic plugins

Twombly puts your project's working screens and design variations side by side on a canvas. This marketplace contains the Twombly skill for coding agents. The current release uses the published Twombly CLI. Open your project, then give your agent this prompt:

> Follow https://raw.githubusercontent.com/materic-inc/plugins/main/SETUP.md to set up Twombly for this agent, then put this project's main screens side by side on a canvas.
