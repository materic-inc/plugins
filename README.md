# Materic plugins

Twombly puts your project's working screens and design variations side by side on a canvas. Install the native Twombly plugin for Claude Code, Cursor or Codex. The plugin includes canvas tools, a skill and comment hooks. For the standalone skill, run `npx skills add materic-inc/plugins --skill twombly`. Open your project, then give your agent this prompt:

> Follow https://raw.githubusercontent.com/materic-inc/plugins/main/SETUP.md to set up Twombly for this agent, then put this project's main screens side by side on a canvas.
