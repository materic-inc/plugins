# Twombly

Get feedback, huddle, and iterate with your team on a canvas beside your agent.

Ask your agent to put two designs on a canvas. Open the private Twombly link to compare them. When you share, choose who can view or edit. An invited editor can open that same canvas with their own agent.

Tick **Send to Agent** on a comment to send the feedback and its frame to your conversation. The plugin connects to Twombly’s hosted MCP at https://twombly.app/mcp. In Claude Code and local Cursor Agents sessions, the checkbox can wake the same finished conversation. Cursor Cloud Agents can read canvas comments with `get_comments`. The canvas and frame files live on Twombly.

In Claude Code, install with `/plugin install twombly --marketplace materic-inc/plugins`.
